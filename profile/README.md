# Hi, we're ICARUS!

ICARUS is a student-led group at [Imperial College London](https://www.imperial.ac.uk) dedicated to designing and taping out chips.

Currently, we're devoting our time to:
- [Jane Street's ASIC challenge](https://blog.janestreet.com/protocol-emulator-asic-competition/)
- [Chipalooza](https://opencircuitdesign.com/chipalooza/index.html)
